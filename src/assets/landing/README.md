# Landing scene assets

Original generated PNGs are retained in `/workspace/generated_images` for this
session; deployed assets are the optimized transparent WebP copies here. No
runtime dependency on generated_images or attachment paths.

- walnut-desk.webp: generated October 22–23, 2026, isolated walnut tabletop,
  narrow far edge, expanding near edge, transparent surrounding area.
- ivory-quill.webp: generated ivory feather, separate layer for positioning.
- cobalt-inkwell.webp: generated blue ceramic inkwell, separate foreground layer.

The user subsequently confirmed that the feather and inkwell should move together.
Image generation supplied transparency; ImageMagick only resizes/encodes WebP.
These are draft assets awaiting visual approval in the actual scene. No text or
controls are baked into these assets. Forest and project previews reuse existing
repository assets. The weather object uses dynamic SVG with actual phase and
available provider conditions. Writing-set drag/editor launch is not yet attached.
